# K8, Helm

This repository demonstrates how to containerize an application and deploy it to a Kubernetes cluster using Kubernetes manifests and Helm.

It includes:
- a basic Kubernetes deployment for a web application
- a service to expose the app inside the cluster
- a Helm chart for packaging and deploying the application with configurable values

The goal of this repo is to show a simple end-to-end example of containerization, Kubernetes deployment, and Helm-based release management.
